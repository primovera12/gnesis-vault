# decision-page

حوّل أي لحظة قد يختلف فيها العقلاء إلى ورقة قرار تفاعلية بنقرة واحدة — ملف HTML واحد مكتفٍ
بذاته، مصمّم بنظام تصميم Genesis (فاتح + داكن). يعرض كل مسار وضعه الحالي، ورأيك الصريح،
والخيارات مع توصية؛ يختار المراجِع ويعلّق ويرسل — بدلاً من سلسلة نقاش طويلة حول المفاضلات.

## ماذا يفعل
- ملف HTML واحد مكتفٍ بذاته لكل قرار — دون أي خطوة بناء، ولا يلزم لعرضه سوى المتصفح.
- بطاقة كل قرار: **من** (الوضع الحالي) · **رأيي** · خيارات قابلة للاختيار مع خيار
  ✓ موصى به. يعرض الشريط السفلي الثابت التقدّم، وصندوق تعليق يتمدّد تلقائياً،
  وزرّ "قبول كل التوصيات"، وزرّ "نسخ وإرسال".
- **الصور:** مقارنة صور جنباً إلى جنب A/B، وخيارات بصورة كاملة العرض، ومعرض تكبير
  (انقر للتكبير، ثم ‹ › / مفاتيح الأسهم / Esc). مثالي لمقارنة التصاميم.
- تُحفظ الاختيارات في `localStorage`؛ ويسلّم خادم محلي اختياري الاختيارات تلقائياً للوكيل.
- مظهر Genesis: عناوين Outfit، ونص Inter، وألوان ink/paper/sky الدقيقة، بوضعين فاتح وداكن.

## التثبيت
```bash
curl -fsSL -o decision-page.tar.gz \
  https://github.com/primovera12/gnesis-vault/releases/latest/download/decision-page.tar.gz
tar xzf decision-page.tar.gz
cd decision-page
bash install.sh
```
